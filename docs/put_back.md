# 原地平稳放回

## 运行

F5 选择 `Task: Physical grasp and put back GUI (0.03 m)`；Ctrl+Shift+B 默认运行同一流程。
原先仅抓起的 headless 任务和夹爪诊断任务保留不变。

在工程根目录运行：

```bash
OMNI_KIT_ACCEPT_EULA=yes ACCEPT_EULA=Y \
../isaac_versions/new/IsaacLab-v3.0.0-beta2.patch1/isaaclab.sh \
-p scripts/smoke_test_integrated_task.py \
--visualizer kit --keep-open --episodes 1 --steps-per-episode 60 \
--pick-lift --put-back --lift-height 0.03 --motion-steps 240 --seed 7
```

去掉 `--put-back` 可保持原先只抓起的行为。不能同时使用 `--stop-after-hold`。

## 控制流程与含义

1. 初始化沉降后记录球心，作为本次“原地”的参考位置。
2. 抓起并通过原有抬升验收后，在空中用球心位置偏差修正夹爪水平目标。
3. 降到球底接触包络距桌面约 8 mm，再用低速、平滑起停的轨迹逐步接近桌面。
4. 球底接触包络距桌面不超过 0.5 mm，停顿后仍满足高度要求，才逐步张爪释放。
5. 张爪后等待软球稳定，检查实际夹爪间隙足够，再向上撤离 10 cm 并复查稳定性。

球底接触包络 = 最低软体节点 Z − 粒子接触半径。它是几何近接估计，不是实际接触力测量。
脚本不绑定节点、不清零放球速度、不传送球，也不修改球/桌面的材料来强行止滑。

## 可调常量（主脚本顶部）

- `ARM_JOINT_SPEED = 1.3`：空载关节轨迹默认峰值，原为 1 rad/s。
- `ARM_CARTESIAN_SPEED = 0.15`：空载撤离轨迹峰值 m/s；平滑起停会增加轨迹时间，不代表整段平均速度。
- 接近球及带球抬升保持 0.10 m/s，避免提速破坏抓取；回落较远段为 0.06 m/s。
- `PLACE_SPEED = 0.015`：最后接近桌面的速度上限 m/s。
- `PLACE_RELEASE_SPEED = 0.005`：单指松爪速度 m/s，逐步卸载软球弹性形变。
- `--motion-steps 240` 为默认时间倍率；480 为慢速。减小它不会突破显式设置的带球/落球/释放速度上限，但空载运动仍会加速。

上述都是仿真时间的速度；GUI 的实际运行耗时仍取决于 Newton 求解速度。

## 验收标准

- 相对原位置的水平误差 ≤ 5 mm。
- 松爪开始至撤离及复查结束，球心相对松爪位置的最大水平位移 ≤ 3 mm。
- 完全张爪后最多 240 步（2 秒仿真时间）达到稳定；这不包括逐步张爪本身的时间。
- 稳定要求沿用原脚本：球心速度 ≤ 1 mm/s、最大节点速度 ≤ 10 mm/s，连续 30 步的水平位置包络 ≤ 0.25 mm，且位于桌面、接触包络高度误差 ≤ 1.5 mm。
- 撤离后至少再检查 60 步。检查失败立即报错，不继续把异常结果当作成功。

成功日志为 `PUT_BACK_RESULT=...` 和 `YAM_DEFORMABLE_BALL_PUT_BACK_OK`；不能只看退出码。
这些指标不保证无限长时间零漂移，也不代表所有随机位置或 0.4 m 高度都已通过。

## 本轮验证（2026-09-13）

一次完整无 GUI 验证通过，参数为上述命令去掉 `--keep-open`、改为 `--visualizer none`：

- 球心实际抬升 26.65 mm（目标 30 mm），原抬升验收通过。
- 放回水平误差 **2.842 mm**（相对初始化沉降后的球心）。
- 松爪至撤离复查的最大水平漂移 **0.338 mm**。
- 完全张爪后 **0.25 秒仿真时间**达到稳定判据；撤离后再检查 0.5 秒。
- 最终球心速度约 **0.262 mm/s**，最大节点速度约 **0.552 mm/s**；不是绝对静止。
- 输出 `YAM_DEFORMABLE_BALL_PUT_BACK_OK`、`YAM_DEFORMABLE_BALL_LIFT_OK` 和集成成功标记。

此前尝试将接近球的下降速度提高到 0.15 m/s，该次球横向移动 6.9 mm，已被保护检查中止；因此最终版只加快空载关节运动和撤离，接近球恢复 0.10 m/s。
