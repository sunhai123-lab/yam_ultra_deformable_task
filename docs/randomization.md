# 桌心机器人与环形位置随机化

> 2026-09-15 修正：本文下方保留上轮实现与实验记录。当前 `yam_pick_ball.py` 的方位范围已改为 `(-2.40, 3.00)`，原来的 `3.54 rad` 上限存在不可达样本；初值偏移不能用于推导真实 joint1 限位。当前学习版同时采用姿态 SLERP 与运动超时报错，详见 [逐函数手册](yam_pick_ball_function_math_guide.md)。本轮没有同步修改旧集成脚本；默认放球 F5 和 Ctrl+Shift+B 均指向学习版。

位置由 `scripts/smoke_test_integrated_task.py` 的 `sample_object_positions()` 生成。程序只创建一次 `random.Random(--seed)`，每个 episode 从同一随机序列继续采样；因此每轮位置不同，同一个 seed 又能复现实验。

## 场景布局

机器人基座固定在各自脚本定义的桌面中心：

```python
ROBOT_BASE_XY = TABLE_CENTER[:2]
```

集成主文件的 `TABLE_CENTER` 是 `(0.12, 0.0, 0.40)`；中文学习版是 `(0.0, 0.0, 0.0)`。两者世界原点不同，但都通过同一表达式把机器人放到各自桌面中心。

机器人基座的 Z 坐标仍为 `TABLE_TOP_Z`，也就是安装在桌面上，而不是嵌入桌体。

球和方块不再各自限制在固定的 Y 半区，而是在机器人周围的环形工作区独立采样：

```python
OBJECT_RADIUS_RANGE = (0.20, 0.30)
OBJECT_BEARING_RANGE = (-2.05, 3.54)
MIN_OBJECT_PLANAR_DISTANCE = 0.18
```

采样先生成半径 `r` 和方位角 `theta`，再转换为世界坐标：

```text
x = robot_x + r cos(theta)
y = robot_y + r sin(theta)
```

- `OBJECT_RADIUS_RANGE` 决定物体离机器人多远。下限形成基座避碰区，上限受机械臂可达距离和桌面短边限制。
- `OBJECT_BEARING_RANGE` 决定物体绕机器人分布的方向。当前约 320° 的范围覆盖桌面四个方向，同时为 joint1 的 `[-150°, 180°]` 限位保留余量。
- `MIN_OBJECT_PLANAR_DISTANCE` 保证球和方块中心至少相距 18 cm，避免初始化重叠，也让搬运任务有实际距离。

最多拒绝并重采样 `SAMPLING_MAX_ATTEMPTS = 100` 次。

## 为什么还要修改 IK

原布局中所有目标大致位于机器人同一侧，所以固定的 `APPROACH_IK_SEED` 和固定世界夹爪姿态可以工作。桌心布局下目标可能位于任意侧，只改机器人和物体坐标会导致侧后方 IK 容易不收敛。

当前实现增加了两项处理：

1. `radial_grasp_rotation()` 根据目标相对机器人的方位旋转夹爪，但夹爪 Z 轴始终保持竖直。
2. `joint1_compatible_bearing()` 按目标方位调整 joint1 的 IK 初值，并把等价角展开到 joint1 限位内。

这样机械臂转动底座去面对目标，腕部不需要独自抵消整圈方位变化。

## 为什么搬运不能再走一条直线

球和方块可能分处机器人两侧。若仍从球到方块做 XY 直线插值，路径会穿过桌面中心的机器人基座。当前搬运会沿连续的极坐标曲线绕行：

```python
MAX_TRANSFER_BEARING_DELTA = math.pi
```

整条路径只使用一次全局 smoothstep。令全局进度为 `u∈[0,1]`，则
`α=3u²-2u³`，并同时插值 `θ=θ0+α(θ1-θ0)` 与
`r=r0+α(r1-r0)`。因此机械臂只在整条搬运路径的起点和终点减速，不会在中间
反复出现“慢—快—慢”。路径仍根据实际软球球心闭环；
`TRANSFER_BALL_ALIGNMENT_TOLERANCE = 0.002` 表示开始下放前，球心与方块中心的
水平误差必须不超过 2 mm。

`MAX_TRANSFER_BEARING_DELTA` 不是路径分段大小，而是一次任务允许的最大起终方位差。
当前取 π（180°）。超过该值的随机组合会重采样，因为 joint1 的可用区间不是完整圆周，
此类组合会迫使机械臂绕大于 180° 的长弧，既慢又容易使软球滑动。

## 如何调整随机程度

想让物体更分散，优先逐步扩大：

```python
OBJECT_RADIUS_RANGE = (0.20, 0.32)
```

不要直接降低半径下限，否则物体可能进入机器人基座或连杆附近；也不要直接设置完整 `(-pi, pi)` 方位范围，因为 YAM joint1 不是无限旋转关节，存在约 30° 的限位缺口。扩大范围后应选择多个 seed 验证四个方向和两物体对侧的情况。

## 已完成验证

无 GUI、Newton 物理后端下完成了两个针对性 episode：

| Seed | 方块 XY（m） | 球 XY（m） | 特征 | 结果 |
| --- | --- | --- | --- | --- |
| 7 | `(0.374, -0.001)` | `(0.265, 0.146)` | 相邻方向 | 抓取、搬运、放置成功 |
| 1 | `(-0.072, 0.094)` | `(0.344, -0.162)` | 相隔约 190° | 绕基座搬运及放置成功 |

对侧测试最终球心相对方块中心的水平误差约为 2.25 mm。当前结果证明新增路径能够处理典型对侧样本，但还不等价于大样本统计成功率；后续可用 10～20 个 episode 做稳定性统计。

默认 `Ctrl+Shift+B` 使用的 `scripts/yam_pick_ball.py` 也对 seed 1 完成了相同对侧测试，结果为 `reset_ok=1 pick_ok=1 placement_ok=1`，最终水平误差约 2.81 mm。
