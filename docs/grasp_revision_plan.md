# 原始夹爪修复与分阶段验收

## 2026-09-12 根因核对

原始 URDF 与生成 USD 均保留。旧脚本运行时新增两块 ContactPad，并关闭机器人原有碰撞；新增板不是原始资产的一部分。已删除新增几何，恢复原始碰撞。

原始指尖内侧平面在 USD tip frame 中：左 y=0.0469184183，右 y=0.0458805300；两 tip 的父坐标平移 y 分别为 0.04694952652、0.04584953082，并绕 Z 旋转约 180 度。因此 q=0 时内侧净间隙约 0.00006211 m，而不是旧代码推测的 0.089 m。

开口公式：gap ≈ 0.00006211 - q7 - q8。q7=q8=-0.04695 时净开口约 93.96 mm；q=0 为闭合。真实夹持中心选 gripper frame z=-0.125 m，对齐指尖直段，所有测量点仅用于诊断，不生成几何。

## 实施与验证顺序

1. `--gripper-check --episodes 1`：固定机械臂，原始夹指张开→闭合→张开。输出实际关节位置和真实表面间距。闭合间隙应小于 5 mm，张开应大于 85 mm。F5 默认项和 Ctrl+Shift+B 先执行此项。
2. `--pick-lift --stop-after-hold --episodes 1`：预抓取→张开门控→缓慢下降→独立夹爪 ramp→保持。阶段误差不满足条件就报错；先观察原始 convexHull 与球接触是否稳定。
3. `--pick-lift --episodes 1 --lift-height 0.03`：在前项基础上垂直抬升。连续 1 秒检查最低节点减去粒子半径高于桌面 2 mm、球仍在夹指区域、球心实际升高达到命令的 85%。禁止为得到 PASS 而下调阈值。
4. 单个位置通过后，再做多随机种子及 5/10 cm 抬升，最后才做放置。

继续复用现有入口，避免新脚本复制场景和控制代码。独立诊断通过参数选择；尚未实现独立于 IK 的固定夹爪软球接触夹具。

## 对参考计划的修正

- 球有旋转对称性，但夹指没有；仅位置 IK 不保证夹爪保持朝下，仍需姿态约束。
- 球心在桌面以上 2–3 cm 不能证明离桌，半径已是 4 cm；应检查最低节点及接触厚度。
- sigma/E_eff 只是闭合量启发式，并非弹性球夹持的精确解。夹紧力、摩擦、接触几何及粒子半径同样影响结果。当前摩擦参数仍是实验值，没有真实材料标定。
- 当前使用原始凸包碰撞近似，保留全部机器人碰撞。以前关于“双凸包接触必然崩溃”的判断没有充分隔离证据，需要重新验证；不能通过新增板或节点绑定绕过验收。
- 形变门控目前是包围尺寸检查，不是去除刚体旋转后的应变计算；区域检查也不能替代双侧接触力证据。
