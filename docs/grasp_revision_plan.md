# 原始夹爪抓取、放置与验收说明

## 当前状态

当前 `scripts/smoke_test_integrated_task.py` 已经在项目 Isaac Lab / Newton 环境中完成整条脚本化流程的运行验证，包括：

1. 动态刚体方块与 VBD 可变形球受限随机初始化；
2. 两个物体进入稳定状态后才开始操作；
3. YAM Ultra 预抓取、下降、原始夹指闭合；
4. 闭合后的快速夹持稳定性检查；
5. 软球离桌抬升；
6. 可选放回原位 `--put-back`；
7. 可选搬运到动态刚体方块顶部并释放 `--place-on-block`；
8. 松爪、撤离、最终稳定性检查；
9. 多 episode 运行及每轮结果与耗时统计。

这里的“运行验证成功”仅表示当前脚本在下面定义的**受限测试场景**内满足现有验收条件，不代表机械臂在完整工作空间、任意物体姿态或任意材料参数下都具有通用抓取能力。

## 夹爪几何与碰撞处理

原始 URDF 与生成 USD 均保留，不再增加 ContactPad，也不使用节点绑定。

原始指尖内侧平面在 USD tip frame 中：左 `y=0.0469184183`，右 `y=0.0458805300`；两 tip 的父坐标平移 y 分别约为 `0.0469495`、`0.0458495`，并绕 Z 旋转约 180 度。因此：

```text
gap ≈ 0.00006211 - q7 - q8
```

`q7=q8=-0.04695` 时净开口约 93.96 mm，`q=0` 为闭合。抓取中心使用 gripper frame 的 `z=-0.125 m`。

为了避免把有凹部的整根原始夹指强行近似成一个单一凸包，当前脚本只在运行时把左右 tip 的 mesh collision approximation 设为 `convexDecomposition`。这不会修改磁盘上的机器人资产，也不会添加新的碰撞板。

## 当前物理参数与稳定门控

刚体方块保持为动态 `RigidObject`，质量、材料和接触均由 Newton 正常求解；桌面与方块使用显式普通刚体材料。

可变形球使用固定半径、密度、Young's modulus、Poisson ratio 和 VBD 参数。当前内部阻尼 `k_damp=0.01`，软接触模型使用 `soft_contact_ke=1e4`、`soft_contact_kd=1e-2`、`soft_contact_mu=5.0`。这些数值是当前场景的实验参数，不是经过真实材料标定得到的物性。

软球 reset 不再按视觉半径固定悬空后自由落下，而是读取 VBD nodal state：先对齐随机 XY，再把最低 simulation node 放到 `table_top + particle_radius + 0.5 mm`。节点速度随后清零。

抓取前的 scene settling 会检查方块支撑、方块速度、软球接触高度、球心平均速度、最大节点速度以及连续窗口内的 XY 漂移。抓取模式下使用更短的稳定窗口以减少不必要等待，但仍要求球和方块同时满足稳定条件。

第一个 episode 自然沉降后，脚本会缓存已经落桌的软球 nodal shape；后续 episode 可以复用这份稳定形状并平移到新的随机位置，同时把节点速度清零。因此后续 episode 并不是每次都从原始未沉降网格重新自由落下。

## 随机化不是无约束随机

当前随机测试的目标是覆盖一批**可达且适合现有硬编码操作流程**的位置，而不是从整个桌面或完整工作空间均匀采样。

当前范围为：

| 对象 | X 范围 (m) | Y 范围 (m) |
| --- | ---: | ---: |
| 动态方块 | `[-0.02, 0.28]` | `[0.06, 0.26]` |
| 可变形球 | `[-0.02, 0.28]` | `[-0.26, -0.06]` |

除此之外还有以下限制：

- 机器人基座水平坐标固定为 `(-0.22, 0.0)`；
- 方块和球各自距基座的水平距离必须在 `0.20–0.40 m` 之间；
- 两物体在 XY 平面的距离必须至少为 `0.18 m`；
- 方块和球被安排在不同的 Y 侧区域，因此不会覆盖任意相对位置组合；
- 最多尝试 100 次采样，仍不满足约束则直接失败；
- 只随机 XY，不随机物体朝向；
- 方块始终以水平姿态开始，Z 由桌面高度和固定 reset clearance 决定；
- 球的 Z 由实际最低节点、particle radius 和 reset clearance 决定，不是随机变量；
- 桌面姿态、机器人基座、物体尺寸、质量、材料参数、抓取方向均保持固定。

因此，多随机种子通过只能说明脚本对**这些筛选后的受限位置**具有一定重复性，不能推导为对全桌面或完整机械臂工作空间的随机鲁棒性。

## 抓取与抬升验收

抓取流程目前为：

```text
PRE_GRASP
→ DESCEND
→ CLOSE_GRIPPER
→ QUICK_GRASP_CHECK
→ LIFT
→ QUICK_GRASP_CHECK(lifted=True)
```

下降前会确认夹爪开口足够覆盖软球接触包络；下降后会检查跟踪误差和球的横向位移，避免夹爪在明显偏心时闭合。

闭合后不再仅靠“球还在两指之间”判断成功。`quick_grasp_check()` 同时检查：

- 夹指几何包络已经收紧；
- 夹爪速度已接近停止；
- 球相对夹爪的运动速度足够小；
- 抬升阶段球的最低接触表面已经离开桌面；
- 球心实际上升量达到命令抬升量的最低比例要求。

因此 `YAM_DEFORMABLE_BALL_LIFT_OK` 比早期单纯依赖几何位置的 HOLD 检查更严格。

## 放回与放到方块上的验收

`--put-back` 会把球重新移动到本轮抓取前的位置附近，低速落球、逐步松爪、垂直撤离，再检查最终支撑和位置误差。

`--place-on-block` 会：

1. 抬高球，保证横向搬运时与方块保持足够净空；
2. 横移到动态方块上方；
3. 先快速下降到接近支撑面，再用较慢速度完成最后落球；
4. 在几何接触高度附近停止；
5. 低速松爪；
6. 确认夹指完全离开软球后再撤离；
7. 持续检查软球水平位置、释放漂移、球是否仍在方块 footprint 内；
8. 检查动态方块没有出现超过配置阈值的倾斜或位移；
9. 最后重新进入 scene settling 判据后才打印成功标记。

需要特别注意：方块本身是动态物体。球落在方块上时产生小幅瞬时运动是允许的，但当前代码仍设置了明确的方块位移和姿态阈值。这些阈值属于回归测试规则，而不是普适物理定律。

## 主要测试模式

- `--gripper-check --episodes 1`：只验证原始夹爪张开/闭合几何。
- `--pick-lift --stop-after-hold --episodes 1`：运行到闭合后的快速夹持检查，不抬升。
- `--pick-lift --episodes 1 --lift-height 0.03`：抓取并抬升。
- `--pick-lift --put-back`：抓起后放回原位置附近。
- `--pick-lift --place-on-block`：抓起后搬运并释放到动态方块上。
- 增大 `--episodes`：在受限随机采样条件下重复完整流程。

典型成功标记包括：

```text
GRIPPER_CHECK_OK
QUICK_GRASP_OK lifted=False
QUICK_GRASP_OK lifted=True
YAM_DEFORMABLE_BALL_LIFT_OK
YAM_DEFORMABLE_BALL_PUT_BACK_OK
YAM_DEFORMABLE_BALL_ON_BLOCK_OK
EPISODE_SUMMARY
YAM_DEFORMABLE_TASK_INTEGRATION_OK
```

## 仍然存在的验证边界

当前结果不能证明以下能力：

- 任意桌面位置、任意机械臂可达位姿下都能成功；
- 球和方块出现在同一侧、彼此很近或接近工作空间边界时仍能成功；
- 物体随机旋转后仍能成功；
- 更换球半径、方块尺寸、质量、摩擦、软体刚度后无需重新调参；
- 真实机器人上的夹持力与仿真一致；
- 当前 friction / damping / contact 参数具有真实材料意义；
- 几何和运动验收等价于双侧接触力或力闭合证明；
- 有限时间窗口内稳定等价于长期绝对不滑移；
- 当前硬编码 DLS IK 与固定朝下抓取策略能够替代通用运动规划与避障。

因此，这个脚本更准确的定位是：**YAM Ultra + Newton 可变形球抓取/搬运/放置的受限集成回归场景**，而不是通用 manipulation benchmark。
